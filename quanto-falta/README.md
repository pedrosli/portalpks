# Quanto falta?

Standalone static site (single `index.html`, no build) — a grade calculator for Mackenzie students: stage averages (At1, At2, APA), final average with 2-2-3 weights, how much is needed to pass, and stage/final recovery math.

It is unrelated to the Portal PKS app. It lives in this folder only so a separate Vercel project (root directory `quanto-falta/`) can deploy it.
